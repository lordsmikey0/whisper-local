# Media Local: конвертер аудио/видео и локальный Whisper

Небольшая утилита для Windows с веб-интерфейсом и консольным запуском. Принимает MP3, WAV, M4A, FLAC,
OGG и другие форматы, которые умеет читать PyAV/FFmpeg. Сохраняет текст
на исходном языке рядом с аудиофайлом: `интервью.mp3` → `интервью.txt`.
TXT записывается в UTF-8 с BOM, чтобы кириллица корректно открывалась в Блокноте.
Каждый распознанный фрагмент — отдельная строка, без временных меток.

## Веб-интерфейс — запуск в один клик

Дважды щёлкните **web.cmd**. Откроется браузер по адресу
[http://127.0.0.1:8000](http://127.0.0.1:8000) (также доступен
[http://localhost:8000](http://localhost:8000)).
Выберите или перетащите **один или несколько файлов**, выберите режим и настройки,
нажмите **«Добавить в очередь»**. Файлы начнут обрабатываться автоматически,
по одному. Готовый результат можно открыть на странице или скачать.
В этой же форме принимается **MP4**: Whisper распознаёт его аудиодорожку
напрямую, предварительная конвертация не нужна.
При веб-запуске браузер сохраняет TXT в выбранную вами папку загрузок;
сервер не может записать его рядом с исходным файлом на основании выбора в браузере.

Оставьте окно сервера открытым. Для остановки нажмите **Ctrl+C**.
Все файлы интерфейса локальные, внешние шрифты и CDN не используются.
Галочка **«Без интернета»** включена по умолчанию: используется уже скачанная
модель `small`. При выборе другой модели сначала снимите галочку, чтобы скачать её.

Зависимости на этом компьютере уже установлены. Для установки на другом
компьютере или обновления окружения используйте `setup.cmd`.
Если порт занят, запустите из PowerShell:

```powershell
.\web.cmd --port 8001
```

Запуск вручную без автоматического открытия браузера:

```powershell
.\.venv\Scripts\python.exe -m uvicorn web:app --host 127.0.0.1 --port 8000
```

### Очередь, прогресс и отмена

- Можно добавлять новые партии, пока предыдущие записи обрабатываются.
  Режим, модель, язык и устройство фиксируются для каждой добавленной партии.
- При передаче файлов показан прогресс загрузки. Во время распознавания —
  фактически обработанное время записи, её длительность и процент.
  Загрузка модели и подготовка аудио показываются отдельными этапами без
  искусственного процента. Процент обновляется после распознанного фрагмента,
  поэтому на сложной записи может некоторое время стоять на месте.
- **«Отменить»** убирает ожидающий файл или останавливает активный процесс
  вместе с его дочерними процессами. **«Отменить всё»** отменяет всю незавершённую
  очередь, включая передачу файлов. Уже готовые результаты сохраняются.
- Ошибка одного файла не останавливает остальные.
- **«Открыть»** показывает стенограмму или аудиоплеер; **«Скачать»** сохраняет
  отдельный файл. **«Скачать всё .zip»** собирает все готовые на момент нажатия
  результаты. Повторяющиеся имена в архиве получают суффиксы `(2)`, `(3)` и т. д.
- Обновление или закрытие вкладки не прерывает уже принятые сервером задачи.
  Вернитесь на страницу — очередь и готовые результаты снова появятся.
  Ещё не переданные файлы при закрытии вкладки не сохраняются.
- Незавершённая очередь хранится **до остановки сервера**. При обычной остановке
  активная задача завершается отменой, временные файлы очереди удаляются.
  Готовые результаты автоматически сохраняются в постоянную историю.
  После принудительного завершения Windows остатки временных файлов
  могут сохраниться в `.web-jobs`.

Интерфейс: `static/index.html`, `static/style.css`, `static/app.js`.
JavaScript последовательно отправляет выбранные файлы через `POST /api/jobs`
и опрашивает `GET /api/jobs`. `jobqueue.py` управляет очередью,
`job_worker.py` запускает каждую задачу в отдельном процессе и передаёт
фактический прогресс через JSON. Модель загружается для каждой записи и
освобождается после завершения или отмены. Исходник удаляется после обработки;
готовый результат сохраняется в `history/files` и остаётся после остановки сервера.
Старые синхронные API `/api/transcribe` и `/api/convert` также доступны.

### История результатов

Новые готовые результаты веб-очереди автоматически появляются в разделе
**«История результатов»**. Они доступны после обновления страницы,
перезапуска `web.cmd` и компьютера. Отменённые задачи и ошибки в историю
не попадают; незавершённые задачи после перезапуска не возобновляются.

В истории есть поиск по имени файла, фильтр «Стенограммы / Аудио / Видео», дата сохранения и размер.
**«Открыть»** показывает стенограмму или аудиоплеер, **«Скачать»** сохраняет результат.
Кнопка **«Удалить»** требует подтверждения на странице и удаляет сохранённый
результат с диска и из текущей очереди. Исходный файл на вашем компьютере
не затрагивается. Если файл был удалён вручную, запись помечается
«Файл не найден на диске»; её также можно убрать из истории.

Файлы и база находятся в папке **`history/`** внутри проекта:
`history/files/` — готовые файлы, `history/index.sqlite3` — имена, даты,
параметры и размеры. История хранится до ручного удаления. Для резервной
копии или переноса остановите сервер и скопируйте папку `history` целиком.
Модуль SQLite входит в Python, дополнительные установки не нужны.
Сохранение с одинаковыми именами не приводит к перезаписи: у каждого результата
есть отдельный идентификатор. Консольный `run.cmd` и старые синхронные API
сохраняют прежнее поведение; постоянная история относится к веб-очереди.

### Прослушивание реплик

Перед добавлением файлов включите **«Сохранить аудио для прослушивания реплик»**.
После обработки нажмите **«Открыть»**: над репликами будет плеер. Нажатие на
реплику запускает запись с её временной метки; текущая реплика подсвечивается.
Воспроизведение продолжается дальше по записи. Закрытие результата останавливает звук.
Эта функция работает и без разделения по говорящим: используются фрагменты Whisper.
С разделением по говорящим показываются его реплики и заданные вами имена.

По умолчанию галочка выключена. При включении сохраняется компактная MP3-копия
аудиодорожки целиком, включая звук из видео, без обрезки начала и пауз.
Исходный загруженный файл удаляется после задачи, как раньше. Копия хранится в
`history/audio/`, временные метки — в таблице `playback_data` существующей базы.
Плеер поддерживает перемотку без загрузки файла целиком. Размер в истории включает
аудиокопию. Удаление результата удаляет и её; TXT и ZIP содержат прежние текстовые
результаты. Дополнительные библиотеки и модели для прослушивания не нужны.

Для старых результатов без аудиокопии доступен обычный текст. Чтобы получить
прослушивание, обработайте исходную запись заново с включённой галочкой.

### Говорящие и таблица имён

В режиме распознавания доступна галочка **«Разделять по говорящим»**.
Она добавляет к репликам временные метки и обозначения «Говорящий 1»,
«Говорящий 2» и т. д. После обработки откройте результат: в таблице
**«Кто говорит»** можно задать соответствия, например
`Говорящий 1 → Джон Доу`, и нажать **«Сохранить имена»**.
Имена попадут в текст на странице, скачиваемый TXT и ZIP текущей очереди.
Они сохраняются в истории после перезапуска. Пустое имя возвращает
исходную метку. Каждая запись имеет свою таблицу: это не узнавание личности
по голосу и не автоматическое сопоставление людей между разными файлами.

На этом компьютере библиотеки говорящих уже установлены и проверены в обеих копиях проекта. Веса Community-1 ещё не скачаны: начните с принятия условий доступа и скачивания модели в интерфейсе.

Первоначальная настройка (один раз для каждой копии проекта):

1. Запустите **setup-speakers.cmd**. Он создаст отдельную `.diarization-venv`
   и установит pyannote.audio/PyTorch. Основное окружение Whisper не меняется.
   Потребуются интернет и несколько гигабайт свободного места.
2. Войдите на Hugging Face и самостоятельно примите условия доступа
   к [pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1).
   Для этого сервис требует учётную запись и согласие с условиями модели.
3. Создайте [токен чтения модели](https://huggingface.co/settings/tokens).
4. В интерфейсе раскройте **«Настройка говорящих»**, введите токен и нажмите
   **«Скачать модель»**. Дождитесь проверки готовности. Токен нужен только
   для скачивания с Hugging Face; приложение не сохраняет его в базе,
   истории, файлах настроек или браузерном хранилище.

После подготовки галочка станет доступна. Если число участников известно,
его можно указать в необязательном поле; пустое поле оставляет автоопределение.
При недостатке доступа появится сообщение об ошибке, обычное распознавание
останется доступным. Для переноса автономной модели скопируйте целиком
папку `models/pyannote-community-1` вместе с `.ready`, а окружение установите
на новом компьютере через `setup-speakers.cmd`.

Сначала Whisper получает текст и временные метки слов, затем отдельный процесс
pyannote определяет голоса. На ноутбуке с 4 ГБ VRAM диаризация намеренно
выполняется на CPU; GPU остаётся для Whisper. После загрузки pyannote работает
из локальных весов с отключённой телеметрией и автономным режимом Hugging Face.
Отмена очереди останавливает также процесс диаризации. Готовый текст и таблица
имён сохраняются в существующей базе истории (новая таблица `speaker_data`),
старые результаты остаются доступны.

Короткие реплики, шум и одновременная речь могут размечаться ошибочно.
Если голос определить не удалось, реплика отмечается «Не определён».
Обозначения выдаются по порядку появления в стенограмме. Назначение имени
не исправляет ошибочно определённые границы или участника отдельной реплики.
Функция доступна в веб-очереди; консольный `run.cmd` сохраняет прежний простой режим.
Для проверки самой нейросети нужны принятые условия доступа и скачанные веса;
автоматические проверки без токена проверяют разметку, интеграцию и сохранение имён.

### Универсальная конвертация

Выберите **«Конвертировать»**, добавьте аудио или видео и выберите выходной
формат. По умолчанию предлагается MP3 и баланс качества/размера.
Нажмите **«Добавить в очередь»** — прогресс, отмена, ZIP и история работают
так же, как при распознавании. Настройки применяются ко всей добавляемой партии.

| Результат | Форматы |
| --- | --- |
| Аудио из аудио или видео | MP3, WAV, FLAC, M4A, AAC, OGG, Opus |
| Видео из видео | MP4, MKV, MOV, WebM |

На вход принимаются локальные медиафайлы, которые может декодировать FFmpeg,
включая MP4, MKV, MOV, AVI, WebM, MP3, WAV, FLAC и M4A. Кодеки для выходных
контейнеров уже подобраны: H.264/AAC для MP4/MKV/MOV, VP9/Opus для WebM.
Аудиофайл без видеодорожки нельзя сохранить как видео; видео без звуковой
дорожки нельзя преобразовать в аудио. При нескольких дорожках используется
первая видео- и первая аудиодорожка, субтитры и вложения не переносятся.

Основные настройки — формат и качество: меньше размер, баланс или выше качество.
Для WAV/FLAC выбор качества скрыт: это форматы без потерь; сохраняются частота
дискретизации и количество каналов источника. Уже потерянные при предыдущем
сжатии данные они не восстанавливают. Для других аудиоформатов используется
стерео 44,1 кГц (для Opus — 48 кГц).

Блок **«Дополнительные настройки»** раскрывается по желанию:

- Начало и конец отрезка в секундах. Пустой конец означает «до конца записи».
- Для видео: исходное разрешение или ограничение до 1080p/720p/480p.
  Пропорции сохраняются, маленькое видео не увеличивается.
- Для видео: исходная частота кадров либо 24/25/30/60 кадров/с.
- **«Удалить звук из видео»** создаёт видео без аудиодорожки.

Конвертация выполняется на CPU, без модели Whisper и расходования её VRAM.
Процесс FFmpeg входит в дерево задачи и останавливается при отмене.
FFmpeg устанавливается вместе с `imageio-ffmpeg` через `setup.cmd`,
отдельная системная установка не нужна. Поддержка форматов зависит от доступных
декодеров; повреждённые или защищённые файлы могут не открываться.
WebM обычно обрабатывается медленнее H.264. Аудио и видео можно открыть на странице;
если браузер не поддерживает контейнер, скачайте файл и откройте его в плеере.
История старых TXT/MP3 полностью сохраняется, изменение схемы базы не требуется.

Конвертация и распознавание работают в общей очереди и выполняются
последовательно. Для обновления уже запущенного интерфейса перезапустите
`web.cmd` и обновите страницу браузера (Ctrl+F5).

Проверено декодирование результатов всех 11 выходных профилей, обрезка,
уменьшение разрешения, частота кадров, видео без звука и отказ от увеличения
маленького видео. Все 32 автоматические проверки проходят, включая таблицу
говорящих, сохранение имён в TXT/ZIP, защиту токена, автономную диаризацию и сохранение истории после
перезапуска, удаление и обработку отсутствующего или занятого файла, порядок очереди, прогресс,
отмену до и после запуска, завершение дочерних процессов, остановку сервера,
восстановление после ошибок, ZIP и удаление временных файлов.

## 1. Установка

Дважды щёлкните **setup.cmd**. Он создаст `.venv` в этой папке и скачает библиотеки.
Нужен интернет. Библиотеки NVIDIA занимают около 1 ГБ при загрузке;
оставьте несколько гигабайт свободного места для окружения и модели.
Настройки системы и драйвер видеокарты установщик не меняет.

Скрипт использует установленный Python 3.10–3.13 (рекомендуется **3.12 x64**)
либо встроенный Python приложения Codex, если он доступен на этом компьютере.
Для независимости от Codex можно установить обычный
[Python 3.12 x64](https://www.python.org/downloads/windows/) и повторить установку.
Активация окружения вручную не нужна.

Если появляется ошибка `DLL load failed` / `VCRUNTIME140`, установите
[Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).

## 2. Распознавание

**Перетащите один аудиофайл на run.cmd.** Можно также дважды щёлкнуть `run.cmd`,
перетащить файл в открывшееся окно и нажать Enter. Дождитесь сообщения «Готово».
Окно покажет устройство, язык и время уже обработанного фрагмента записи.

При первом запуске утилита скачает Whisper `small` (около 0,5 ГБ) в `models/`.
Следующие запуски используют кэш. Распознавание выполняется на компьютере,
аудиозаписи никуда не загружаются. Для гарантированного запуска без обращения
за моделью в интернет используйте `--offline`.

По умолчанию выбирается NVIDIA GPU с режимом `int8_float16`. При отсутствии GPU
или ошибке CUDA утилита сообщит об этом и повторит обработку на CPU (`int8`).
При повторе после ошибки видеокарты распознавание начинается с начала.

Файл с существующей стенограммой защищён от случайной замены.
Для замены укажите `--overwrite`. Незавершённый TXT при ошибке или отмене
не публикуется; уже существующий результат сохраняется.

## 3. Команды для PowerShell

Откройте терминал в папке проекта. Кавычки вокруг путей с пробелами обязательны.

```powershell
# Обычный запуск, язык определяется автоматически
.\run.cmd "D:\Аудио\запись.mp3"

# Явно указать русский язык
.\run.cmd "D:\Аудио\запись.mp3" --language ru

# Указать место сохранения (папка должна существовать)
.\run.cmd "D:\Аудио\запись.m4a" -o "D:\Аудио\стенограмма.txt"

# Заранее скачать модель, затем работать без интернета
.\run.cmd --download-only
.\run.cmd "D:\Аудио\запись.mp3" --offline

# Принудительно использовать видеокарту / процессор
.\run.cmd "запись.mp3" --device cuda
.\run.cmd "запись.mp3" --device cpu

# Более лёгкая модель
.\run.cmd "запись.mp3" --model base

# Заменить предыдущий результат
.\run.cmd "запись.mp3" --overwrite
```

Вариант без паузы после завершения, удобный для автоматизации:

```powershell
.\.venv\Scripts\python.exe .\transcribe.py "запись.mp3" --offline
```

Код завершения: `0` — успех, `1` — ошибка, `130` — отмена по Ctrl+C.

## Почему эта модель

Используется **faster-whisper** — реализация Whisper через CTranslate2,
с поддержкой 8-битного режима. Для RTX 3050 Mobile с 4 ГБ выбрана многоязычная
`small`, как практичная отправная точка по качеству и потреблению памяти.
Фактический расход зависит от записи и свободной видеопамяти. Если памяти
не хватает, закройте другие программы с GPU или выберите `base` / `cpu`.
`medium`, `large-v3` и `turbo` доступны как дополнительные варианты,
но их работа на 4 ГБ здесь не гарантируется. Модели с суффиксом `.en`
не используются: они предназначены только для английского языка.

Отдельно устанавливать FFmpeg, PyTorch, CUDA Toolkit и cuDNN не требуется:
PyAV, комплект FFmpeg и библиотеки NVIDIA устанавливаются в окружение проекта. Нужен рабочий
драйвер NVIDIA. Состав библиотек GPU в `requirements.txt` рассчитан на Windows x64;
на Linux их установка настраивается отдельно.

Whisper может ошибаться в именах, числах, на шуме и музыке. Включён фильтр
тишины VAD. Разделение по говорящим включается отдельно в веб-интерфейсе; перевод текста не выполняется.
Длительные файлы обрабатываются фрагментами моделью, но декодированное аудио
загружается в оперативную память. Для многочасовых записей может понадобиться
предварительное разделение файла.

Документация: [faster-whisper](https://github.com/SYSTRAN/faster-whisper),
[CTranslate2](https://github.com/OpenNMT/CTranslate2).

## Проверка проекта

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки защищают сохранение TXT при ошибках, существующие файлы и повтор
на CPU после сбоя GPU. Они не оценивают точность распознавания речи.

### Результат проверки на этом компьютере

Окружение установлено, модель `small` скачана. Уже можно запускать `run.cmd`,
повторная установка не нужна. Проверены FLAC и MP3, имя файла с кириллицей
и пробелом, автономный запуск с `--offline`, совместимость зависимостей
и 38 автоматических проверок. Запись длительностью около 11 секунд
распознана на CPU примерно за 4–6 секунд (это пример, не обещание скорости).
Использована [тестовая запись Whisper](https://github.com/openai/whisper/blob/main/tests/jfk.flac).

Причина ошибки `no CUDA-capable device is detected` найдена: пользовательская
переменная Windows `CUDA_VISIBLE_DEVICES=1` скрывала единственную NVIDIA-карту,
которая имеет индекс 0. После выбора индекса 0 проверено настоящее распознавание
на RTX 3050 в режиме CUDA / `int8_float16`.

`web.cmd` и `run.cmd` задают `CUDA_VISIBLE_DEVICES=0` только для своих процессов
и дочерних задач. Системные настройки Windows не меняются. Встроенная Intel
не входит в нумерацию CUDA-устройств. Если запускаете Python вручную, сначала
задайте в той же PowerShell-сессии:

```powershell
$env:CUDA_VISIBLE_DEVICES = '0'
```

Затем используйте `--device cuda` для проверки GPU без перехода на CPU.
Для компьютера с несколькими NVIDIA-картами при необходимости измените индекс
в файлах запуска. Подробнее: [переменные окружения CUDA](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/environment-variables.html).
